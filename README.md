# 한줄 (hanjul)

> 오늘 배운 한 줄, 광명의 배움 피드.

수업 시간표는 학교가 알려주고, **배운 것은 학생이 한 줄로 남깁니다.**
상세 기록은 나만 보고, 공개를 선택한 한 줄만 같은 지역 친구들과 나눕니다.

- **서비스명**: 한줄 (hanjul)
- **한 줄 소개**: 시간표로 자동 채워지는 10초 학습 기록 + 광명시 배움 피드
- **개발 배경**: 2026 지역연합 해커톤
- **주요 문서**: [PRD.md](./PRD.md)

## 핵심 기능

| 기능 | 설명 |
|---|---|
| 시간표 자동 채움 | NEIS 시간표 API로 오늘 교시·과목 자동 입력 |
| 10초 기록 | 한 줄 + 활동 태그 + 막힌 개념 |
| 공개 토글 | 기본 비공개, 선택한 글만 광명시 피드에 공개 |
| 주간 리포트 | 나만 보는 막힘 TOP 3, 과목 분포 |
| 지역 막힘 TOP | 익명 집계로 오늘 광명시에서 가장 많이 막힌 개념 |
| 시험 D-day 리콜 | 학사일정과 연동한 간격 반복 복습 |

## 빠른 시작

```bash
# 1) 환경 변수
cp .env.example .env
#    .env 에 NEIS_KEY, (선택) OPENAI_API_KEY 입력

# 2) 의존성
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 3) 실행
streamlit run app.py
```

## 보안

- `.env` 는 **절대 커밋하지 않습니다** (`.gitignore` 에 포함).
- 저장소에는 `.env.example` 만 포함합니다.
- 공개 글에는 학교명·실명·위치·연락처를 남기지 않습니다.
